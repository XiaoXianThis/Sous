# 本机工作区

本机工作区与已配对的 Sous 工作区独立：不用中继，也不会改写旧工作区的数据库。当前可保存对话、管理项目资料、记忆和手动任务；带沙盒模块的 Apple Silicon 桌面预览包另支持[待本机授权执行](local-sandbox.md)。桌面首次默认选兼容主管，未设置模型时不会自动回复。使用联网模型时，上下文会发给该模型服务；只使用本地工作区并不等于所选模型离线。

## 使用桌面版

1. 先构建 Core 和 WebUI：`wok build core web`。在 macOS 上用 `wok build desktop`；Windows 打包用 `wok run core build-windows` 后运行 `wok run desktop build-windows`。
2. 启动 Sous 即显示内置工作台。macOS 点击「验证并解锁」，跟随系统提示验证身份，可使用系统提供的登录密码选项。非 macOS 桌面保留内置窗口的 Passkey 路径，取决于系统 WebView 支持。
3. 在工作台登记项目资料，或创建不依赖执行机器的手动任务。本机工作区不会扫描宿主项目目录或自动执行任务。
4. 可以在「设置 → 账号」锁定；退出桌面版后由它启动的本机 Hub 停止。配对的机器和旧工作区保持原有入口。

## 调试登录（macOS 开发包或 Alpha）

支持调试登录的包可用 `open -n -a /path/to/sous.app --args --debug-login` 启动（先退出另一份 Sous）。在内置工作台点击「显示验证码」，关闭原生提示后输入 8 位验证码。验证码 2 分钟内有效、只能使用一次；多次输错需要重新生成。

只对 `dev` 和显式启用的 Alpha 桌面构建生效，使用独立的 `SOUS_HOME/desktop-debug/`，默认不启用主管。调试会话不授权主管绑定等需要近期系统验证的操作，也不能替代沙盒的原生目录、执行和写回确认。退出后正常启动即可恢复使用非调试工作区。

## 使用命令行

用构建后的 `sous` 执行 `sous hub --web-dir <WebUI 构建目录>`，按终端显示的链接注册或解锁。默认使用独立的 `SOUS_HOME/workspace/`（未设置时在用户的 `~/.sous` 下），不能同时运行两个 Hub 操作该目录。CLI 默认无主管；需要使用旧模型管理和对话能力时，显式传入 `--agent legacy`。如果端口被其他进程占用，先停止占用进程或通过 CLI 的 `--listen` 选择另一个回环端口；不要把本机工作区反代到公网。


## 试用独立 ACP 主管

桌面在「设置 → 主管」中可选「不使用主管」「兼容主管」或「Sous ACP 主管」，不需要重启工作区。选择 ACP 前，在 `SOUS_HOME/supervisor.yaml`（默认 `~/.sous/supervisor.yaml`）保存由你控制的模型配置。CLI 也可用 `sous hub --web-dir <WebUI 构建目录> --agent acp --agent-config <模型 YAML>` 静态装配。

例如，已在本机运行兼容 Chat Completions 的服务时，填写模型名与服务实际使用的基础地址：

```yaml
kind: openai-chat
model: your-local-model
base_url: http://127.0.0.1:1234/v1
```

`kind` 也可选 `openai-responses` 或 `anthropic-messages`，前提是选用的模型服务实现对应接口。若需要密钥，用 `api_key_env` 指定环境变量名，不把密钥写进 YAML。若使用外部 HTTPS 模型服务，对话文本、摘要和调用所得的工具结果可能会发送给该服务；需要离线时只选本机模型。浏览器不会直连模型服务。

ACP 预览仅支持第一方文本主管，可查项目名称和 ID、在主对话查询记忆、在用户回合登记一条待分配任务。不会读宿主项目文件、派发任务、执行命令或审批；附件和会议不属于此模式。正在回答时可「停止本轮」，已经保存的草稿仍保留。应用 ACP 选择前会做一次真实连通测试，只发送合成内容。测试失败保留旧选择；若已有在途回合，主管保持原样，等待完成（或显式停止）后再试。切换保留工作区的数据和任务状态，未回复的消息会交给新主管。修改本机 profile 后使用「重新连接 ACP」验证并应用；选中期间只使用已验证的配置，重启时检测到改动也不会自动连接。若只希望保存工作内容、不向任何模型发送上下文，先选「不使用主管」。
