# rules

Detailed rules by topic, such as `git.md`, `testing.md`, or `code-review.md`. `AGENTS.md` holds the global rules; longer topic rules live here.

## Rules

- These are rules too: adding, changing, or deleting one needs user approval.
- One topic per file, kebab-case file names.
- Start each file with when it applies. Agents read it when that situation comes up.
- When a rule here conflicts with `AGENTS.md`, `AGENTS.md` wins.
