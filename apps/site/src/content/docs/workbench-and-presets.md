## 1. 自定义预设（Presets）

**为什么要用预设**：不同任务的性价比需求完全不同——跨模块架构改造需要推理最强的模型（如 Claude Code + Opus + `high` 思考强度），而改几行文案或补一个简单单测用轻量快速的组合（如 Codex 或 Cursor 快速模型）就够了。把这些组合保存为预设，主管就能按你在「定位」里写的说明自动挑选。

### 配置步骤

1. 先让机器探测一次 Agent 支持的模型选项：
   - 打开 **设置 → 机器 → 管理**（针对某台在线电脑），在你要用的 Agent 卡片上点击 **读取选项（Probe）**。
   - Node 会启动该 Agent 读出可选的模型列表（`model`）与思考强度（`thought_level`）。
2. 打开 **设置 → 预设**，点击新建预设并填写：
   - **名称**：例如 `主力深思`、`快速修补`、`低成本调研`。
   - **Agent**：选择 `claude`、`codex`、`cursor`、`opencode`、`kiro` 或留空。
   - **模型与思考强度（`options`）**：从探测出的下拉列表中选择模型与思考强度（`low` / `medium` / `high` / `xhigh` / `max`）。
   - **默认权限模式（`default_mode`）**：推荐设为 `auto`（自动审批）。
   - **定位（`brief`）**：用一两句话写给主管看，例如「架构设计、疑难 Bug 排查、跨多文件修改时使用」或「单文件小改动、修拼写、格式化时使用」。
3. **查看可用机器**：预设保存后，页面会自动标出当前有哪些电脑安装了该 Agent 且处于已登录状态。
4. **设为项目默认或临时指定**：
   - 你可以在项目设置里把某个预设设为该项目的 `default_persona`；
   - 也可以在对话里直接跟主管说：「用『快速修补』预设帮我把 typo 改了」，或者「这次任务用 claude 的 sonnet 模型、思考强度 medium」。

## 2. 审批怎么减少打断

如果你觉得任务执行过程中弹出的「等你审批」太多，可以按以下五个层次逐步减少打断，同时不牺牲安全底线：

### 第一步：将默认权限模式设为 `auto`

打开 **设置 → 通知与默认**（或项目设置），确认默认权限模式为 **`auto`（自动审批）** 而非 `default`：
- 在 `default` 模式下，除了工作树内读写和安全测试命令（`go test`、`bun test`、`cargo check` 等）之外，几乎所有命令都会直接找你审批。
- 在 `auto` 模式下：
  1. **常规操作（Routine）由 Node 本地直接秒放**：包括 `git push [-u] origin <非受保护分支>`、`gh pr create/view/edit/diff/checks`、删除 `node_modules` / `dist` / `build` / `target` / `.cache` 等构建产物；
  2. **其余无硬信号的操作交给审批 Agent（`approver`）**：审批 Agent 会自动结合命令附带的脚本证据以及只读 `inspect` / `read_file` 工具核实安全性，高把握时直接放行。

### 第二步：为 `approver` 角色配置稳定快速的模型

打开 **设置 → 模型**，检查 **审批（`approver`）** 角色：
- 如果未设置审批模型、或者审批模型连续调用失败，所有需要 AI 判断的请求都会退回给你人工审批。
- 给 `approver` 选一个响应快、遵循 JSON 指令稳定的模型，能显著提升自动放行率。

### 第三步：对同一任务中重复执行的操作点「始终允许」

当某个无害但需要人工确认的操作（例如在特定外部目录执行构建脚本）弹出审批时：
- 如果只是工作台卡片上的快捷条（`ApprovalStrip`），点击按钮默认是 **允许这一次（`allow_once`）**；
- 如果预计子 Agent 在这个任务里还会多次运行完全相同的命令，**点开任务详情页**，在完整审批卡片上选择 **始终允许（`allow_always`）**。只要仍在同一个任务内、且执行目录、分支、参数和脚本文件的全文 SHA-256 没有变化，后续调用就会自动复用你的决定。

### 第四步：让子 Agent 把脚本放在工作树内，避免混入硬信号词

根据 Node 的评估规则（`apps/core/internal/policy`）：
- 如果子 Agent 用 `python -c` 或长串内联命令操作，或者命令里带了 `--no-verify`、`curl -k`、读写 `.env`（非 `.env.example`），会触发高风险信号而转交人工。
- 让子 Agent 把辅助脚本写在仓库的 `work/tmp/` 下（Node 能完整读取树内脚本全文并计算 SHA-256 证据交给审批 Agent），审批 Agent 就能看清脚本内容并自动放行。

### 第五步：在开发机隔离环境下对特定低风险任务使用 `open`

如果你在一台不含敏感凭据的开发机上跑需要频繁启停容器或修改树外目录的任务，可以在创建任务时让主管将该任务的权限模式设为 **`open`（完全开放）**。即便在 `open` 模式下，Node 本地的 13 条底线规则（`DefaultFloor`）依然会拦截删主目录、格式化磁盘和 `curl | sh` 等毁灭性命令。

## 3. 任务进展与结果怎么看

`sous` 把信息按「概览 → 阶段 → 详情」分成三层，避免满屏滚动日志：

1. **工作台项目卡片（一眼看全局）**：
   - 顶栏右侧显示全局数字概况：**正在执行**、**要你处理**（待审批 + 收件箱任务，点击弹出列表）、**待办**、**在线机器数**。
   - 正在运行的任务会在项目卡片内展开一张 **Agent 卡**，实时显示接手的预设、Agent、模型、思考强度、所在电脑，以及最新 2 行工具活动或子 Agent 通过 `report_progress` 上报的阶段进度。
   - 需要你审批时，Agent 卡或任务行的输出摘要格会原地变成 **`ApprovalStrip`**（卡片高度不变），当场就能点「允许这一次 / 拒绝」。
2. **右侧聊天栏（看汇报与主管动作）**：
   - 主管自己调用的工具（如 `project_read`、`task_create`）默认折叠在助手消息下方的一行「`▸ 调用了 N 个工具`」里，点击即可展开查看参数摘要。
   - 每个 Run 在对话流里只占一行 `RunChip`，不会用长篇终端日志刷屏对话。
   - 当任务完成、受阻或验收结束时，任务引擎会发出一张结构化的**任务汇报卡片**，清晰列出 `## 结果` 的五项内容（**做了、改动、验证、没做完/风险、需要决定**）。
3. **项目弹窗 → 任务详情（查完整步骤、日志与 Diff）**：
   - 点击工作台上的任意任务行（或访问路由 `#/task=<id>`），会打开该项目弹窗并定位到右侧的 **任务详情（`TaskView`）**：
     - **顶部与底部信息栏**：固定展示任务状态、阶段条（`StageBar`）、预设、Agent 与机器、执行位置（`worktree` / `in_place` / `scratch`）、起点分支、去向状态（未合并 / 已合并 / PR 已开）以及验收方式。
     - **等你验收操作栏**：若任务设置了 `review: user` 且处于「等你验收」，顶部下方会直接出现 **通过 / 要改** 按钮；点「要改」填入原因即可让 Agent 在原会话基础上返工。
     - **执行记录（Run 历史）**：按时间倒序排列每次 Run。最新一次 Run 默认展示提示词与最终 Markdown 总结；点击 **「执行过程 · 时长」** 可展开查看完整的计划（Plan）、每一步工具调用、思考过程（Thinking）和原始输出日志，也可查看相对于基线提交的完整 **Diff**。

## 4. 产物浏览、在线预览与项目终端

除了看 Diff，你还可以直接在网页工作台上浏览项目文件树、预览生成的文档/图片，或者打开终端跑预览服务。

### 在线浏览、预览与编辑文件（`FileTree` + `FileEditor`）

1. 在工作台项目卡片上切换到 **详情** 标签（或点击项目卡片右上角的放大按钮打开项目弹窗），左侧会懒加载该项目在当前在线机器上的实时目录树（自动隐藏 `.git`）。
2. 点击任意文件即可在右侧打开查看器/编辑器：
   - **Markdown（`.md`）与 SVG（`.svg`）**：**默认直接展示渲染后的预览效果**，顶部可一键切换到「源码」视图。
   - **图片文件（`.png` / `.jpg` / `.gif` / `.webp` / `.bmp` / `.ico` / `.avif`）**：直接在线渲染预览图片。
   - **代码与文本文件（1 MB 以内）**：按扩展名自动语法高亮，支持直接在网页上修改代码并按 `Cmd+S` / `Ctrl+S` 保存（保存时通过 `base_sha256` 校验防止覆盖他人或 Agent 刚刚写入的改动）。

### 打开项目本机终端（启动开发服务器或验证产物）

如果你需要在项目目录里亲手跑一条命令或启动预览服务：

1. 打开项目弹窗，切换到第三个标签 **终端（Shell）**。
2. 点击 **+** 选择该项目所在的一台在线机器（若距离上次验证 Passkey 超过 15 分钟，会提示「验证并打开」刷新一次近期认证）。
3. 浏览器会通过伪终端（xterm）直接打开那台机器上该项目目录里的登录 Shell（注入 `SOUS_SHELL=1`）。你在里面输入的命令属于你本人操作，不经过 Agent 权限策略，终端输出也不会写入 Hub 数据库。
