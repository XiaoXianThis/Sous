# 现场：谁在给谁派活

工作台标题旁可以在“项目”和“现场”之间切换（记在 localStorage `sous.wbView`，手机和电脑都有）。现场是一张实时的 2.5D（等距）图，像模拟经营游戏，正好占满工作台的内容区，页面本身不滚动；上面仍是工作台的概况（进行中、要你处理、待办、机器在线）：画的是人、事、物之间怎么流转，不画系统模块（接口、事件日志、模型路由这些在设置的“系统状态”里，见 [system-map.md](system-map.md)）。

- 数据：工作台的 overview（任务、Run、审批、机器）和 `/ws` 的实时事件。页面打开时用 `/ws?since=` 把最近 600 条事件读回来，填进“动态”，不播动画。不需要额外的接口。
- 代码：`apps/web/src/components/Workbench.tsx`（视图切换）、`apps/web/src/lib/dispatch.ts`（现场和事件 → 交接的规则，纯函数，有测试）、`lib/office.ts`（平面图、寻路、相机、颜色，纯函数，有测试）、`lib/dispatch-draw.ts`（Canvas2D 绘制）、`components/Dispatch.tsx`（现场本身）、`components/DispatchDialogs.tsx`（弹窗）。

## 布局

整层是一个开放式办公室：一块连续的地板，没有墙，也没有走廊，各个区域只用淡淡的底色和细线分开。最上面是你的角落和调度区，下面是机器的工位区，大小一样，整齐排成网格。送东西的小人直接在地板上横着、竖着走。除了木桌、软木看板和一座落地钟，不放别的装饰。

有两种看法，右上角工具条上切换（记在 localStorage `sous.sceneView`；第一次打开时手机默认 2D，电脑默认 2.5D）：

- **2.5D**：斜着看（等距）。每行两块工位区（机器超过 8 台时三块），你的角落和调度区并排在最上面。竖屏时一开始放大在你的角落和调度区上。
- **2D**：从正前方俯视，画面占满整块面板。每行放几块工位区，按面板的形状挑（手机竖屏可能只有一块一行，这时你的角落在调度区上面）；地板的纵深在一定范围内伸缩，让整层正好铺满，再缩到 90% 显示，四周留一点空。工位区的名牌是一行，贴在区域的下边；看板栏窄时只写两个字或只写数字。

两种看法都给工具条留出顶部的位置，不会挡住看板。

```mermaid
graph LR
  you["你的角落"] --- hall["调度区：主管、验收员、审批员、巡检员、落地钟、任务看板"]
  hall --- shops["每台机器一块工位区：每个并发一个工位"]
```

- **你的角落**：你坐在桌前，桌上一摞纸是等你批的请示（人工审批，或审批员转给你的），名牌写“N 件待你批”。
- **调度区**：主管在中间。正在回复某个对话时，它穿强调色、敲键盘，头上有“…”。验收员、审批员是主管的帮手，经手东西时会忙一下；审批员桌上的纸是它正在看的请示。巡检员在屋前来回走，名牌跟着他。角落的落地钟走真实时间。
- **任务看板**：立在调度区后面，按状态分六栏：待办（inbox、planned、queued）、进行中、等审批、待验收、受阻（blocked、failed）、完成（只留 24 小时内的）。每张卡是一个任务，看板放得下几张就画几张（不会画出看板），栏头写总数。取消的、已关掉的任务不上看板。
- **工位区**：每台机器一块，在线的机器排在前面，离线的那块地板变暗。工位数是机器的并发数（干活的 Run 更多时会加座）。工位上坐着干活的 agent，头上是它的品牌标志和名字；放大或悬停时还会显示它在做哪个任务、最新一步在干什么。agent 等审批时会举手，暂停时打瞌睡。排队的 Run 拿着工单站在门口。一个 agent 换走后，其他 agent 留在原来的工位上。工位前面的地上立着牌子，写机器名和“N/M 个工位在干活 · K 个排队”。

## 交接

每个值得看的事件，都是一个强调色的小人拿着东西，在地板上从一处走到另一处。头上标着做的事；失败、驳回、退回用深色标签。只在原地发生的事，画成头顶的气泡。

| 事件 | 画面 |
|---|---|
| 你发的消息 | 纸条：你 → 主管 |
| 主管的回复、汇报、通知 | 信：主管 → 你 |
| 主管用工具（上网、看机器、翻代码…） | 主管头上的气泡 |
| 定时任务到点、该跟进了 | 纸条：挂钟 → 主管 |
| 建任务 | 工单：主管 → 看板对应的栏 |
| 任务换栏 | 工单：看板一栏 → 另一栏 |
| 派发 Run | 工单：主管 → 那台机器的工位区 |
| 追加指令 / 顾问回答 | 便条：主管 ↔ agent |
| 请求审批 | 请示单：agent → 你（或审批员） |
| 转给你批 | 请示单：审批员 → 你 |
| 审批结果 | 印章：你（或审批员）→ agent |
| Run 结束 | 包裹：agent → 主管（交付、失败、取消、中断） |
| 验收结论 | 印章：验收员 → 看板的完成或受阻 |
| 巡检发现 | 便条：巡检员 → 主管 |
| 机器上线、下线 | 工位区里的气泡 |

同一方向 0.7 秒内的几件合成一个人，标“等 N 件”，同时最多 16 个。系统设置“减少动态效果”时，小人不走动，只在目的地冒气泡。

## 操作

- 点人、点看板的一栏、点工位区、点小人或气泡，打开弹窗：经手过的事、等批的请示、栏里的任务、工位区的工位和排队、一次交接的来龙去脉。点 agent 打开它的 Run 详情。
- 现场右上角的工具条：只看一件事、动态、看全图、暂停。“动态”是弹窗，默认不打开，按钮上的数字是上次看过之后的新交接；弹窗里用人话列出每次交接（时间、做的事、谁 → 谁）。
- 可以只看一件事（一个任务及其 Run）；任务详情、Run 详情、对话标题栏的“在现场里追踪”（路由 `view: 'system'`）打开现场并带上这个筛选，其余的人和物变淡，也不再走动。
- 拖动平移，滚轮或双指缩放，“看全图”回到适应窗口；暂停只停动画，动态照常记录。

## 画法

- 状态只用黑白灰和强调色，跟随浅色深色主题；木色家具、软木看板、绿植是装饰，agent 的品牌标志是身份，都不表示状态。
- 画面不闪：绘制循环只在页面打开时建一次，数据变化只更新场景读取的输入；画布只在尺寸真的变了时才重设大小（重设会清空画布），而且重设后在同一个尺寸回调里立刻重画，所以拖动浏览器窗口改变大小时不会出现空白的一帧。
- 手机上：切换在顶栏左边；现场时概况（进行中、要你处理、待办、机器在线，只有图标和数字）并进现场的工具条左边，工具条右边是筛选（漏斗图标）、动态、2D/2.5D、看全图，没有暂停；画面一开始放大在你的角落和调度区上（竖屏里整层楼会太小），拖动看工位区，“看全图”看整层；缩得很小时只留需要你注意的名牌，agent 只显示标志。拖动和双指缩放都在画布里，不会滚动页面。
