# 外部 MCP：授权一个托管项目

外部客户端直接连接一个 Sous 云工作区，即使工作区没有主管、个人电脑全部关机，也能读授权项目或创建任务草稿。默认关闭；此实现支持**运维预注册的公开客户端**，精确 HTTPS 回调、OAuth PKCE S256、带资源指示符的 Streamable HTTP。已用官方 MCP Go SDK 的独立客户端和真实浏览器 Passkey 流程验证；未验证 ChatGPT、其他第三方产品的注册或互操作，不应假定客户端仅粘贴 URL 即可用。

## 运维：注册一个可信客户端

让客户端提供自己的公共 `client_id` 和准确的 HTTPS 回调。在该工作区 `hosted.yaml` 添加 `external_mcp_clients` 后重启 Hub，例如（替换为你的注册信息）：

```yaml
external_mcp_clients:
  - id: project-client
    name: 项目助手
    redirect_uri: https://client.example.com/oauth/callback
```

工作区的 MCP 入口是现有规范 HTTPS origin 加 `/mcp`。客户端从资源元数据发现同源授权端点；发起请求时必须发送该完整资源 URI、`state` 和 PKCE 信息。需要创建草稿时请求 `project.read drafts.write`，只读时请求 `project.read`。不支持工作区本机入口、动态客户端注册、浏览器跨域请求、HTTP 回调或复用旧中继身份。[协议与工具清单](../api/core-external-mcp.md)

## 使用者：选项目、看范围、允许或拒绝

客户端会打开 Sous 的授权页。用 Passkey 登录，核对客户端名称和回调地址，选择一个未归档项目。只读会共享项目名称、任务标题、状态和说明。只有主动勾选「允许创建任务草稿」才允许外部写入；草稿与 WebUI 在同一项目里可见，不会自动派发。它不会获得记忆、对话、目录、终端、审批或执行权限。不要把含密钥等敏感材料的项目授权给不受信任的客户端。

授权最长 7 天。「设置 → 外部连接」可看到该工作区的连接、范围和到期时间，并立即撤销。对方不必在线，已发的访问/刷新凭据也无法继续使用；已经传出的内容不能追回。归档期间不能访问该项目，若希望恢复项目后也不再共享，应撤销该连接。移除客户端或更改注册回调会禁用相应授权。
