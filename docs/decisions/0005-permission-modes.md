# 0005 三档权限模式，加一条底线

- Status: Accepted
- Date: 2026-11-03

## Context

sous 要能自主干活，又不能在用户不知情时做出不可逆的事。不同项目和任务需要的放手程度不同。

## Decision

提供三档模式，可以设置全局默认值，再按项目或按任务覆盖：

| 模式 | 行为 |
|---|---|
| 默认 | 读文件、在 worktree 内改代码、跑测试直接放行；push、删除文件、安装依赖、在 worktree 之外执行命令需要用户审批 |
| 自动审批 | 原本需要用户审批的操作，先交给审批 agent 判断；它拿不准的，以及不可逆的高风险操作，再转给用户 |
| 完全开放 | 全部放行，只记录日志 |

另有一份底线规则（比如删除 home 目录、格式化磁盘），任何模式下都直接拒绝。底线写在 Node 本地配置里，用户可以关闭。

## Alternatives

- 只有一种固定模式：要么太烦，要么太危险。
- 设置花费上限来兜底：见 0006。

## Consequences

- 每个操作都要先分类（读、写、执行、网络、git、破坏性），分类规则由 Node 执行。
